## Customer-facing AI chat widget — increase panel size

The current chat widget (`frontend/js/chat-widget.js`, `.chat-widget__panel`
in `frontend/css/styles.css`) looks good visually, but the panel is sized for
a quick Q&A, not a sustained conversation. It should eventually be
substantially larger and more comfortable, especially on desktop (more
message-list height, a wider panel, more breathing room around the
composer). Not done as part of the WhatsApp entry-point task that noted it.
