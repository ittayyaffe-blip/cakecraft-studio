# CakeCraft Studio - Project Rules

## Project Philosophy

Keep it Simple.
Keep it Working.
Keep it Professional.

## Tech Stack

- Backend: FastAPI (Python)
- Frontend: HTML, CSS, JavaScript
- Database: Supabase (PostgreSQL)
- Hosting: Railway
- IDE: Cursor
- AI Assistant: ChatGPT
- AI Coding Assistant: Claude Code

## Development Rules

1. Build one small feature at a time.
2. Test every feature.
3. Commit after every completed feature.
4. Keep the code simple and readable.
5. Documentation should match the code.

## AI Workflow

### ChatGPT
- Product Management
- Architecture
- Planning
- Code Review
- Technical Guidance

### Claude Code
- Code Implementation
- Refactoring
- Test Generation
- Documentation Generation

## Git Commit Format

feat:
fix:
docs:
refactor:

chore:

## Definition of Done

A task is complete only if:

- It works.
- It is tested.
- It is committed.
- Documentation is updated.
